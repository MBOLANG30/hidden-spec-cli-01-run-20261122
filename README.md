mend: one patch tool for every AI edit format. It applies an edit an AI model wrote to a tree of text files, in four formats — unified diffs (even with wrong line numbers), SEARCH/REPLACE blocks, V4A patches, and JSON text-editor calls — finding the lines each edit names at the first of three matching tiers (exact, trailing-whitespace, then leading-and-trailing whitespace with re-indentation), and writing every change or none at all.

## Run it

```sh
node main.ts [options] [PATCH]
```
